# R&D Roadmap

## Milestone 1: Thin End-to-End

One curated anime-style sample runs through skill orchestration, model-service stub analysis, Cubism adapter contract, and web preview metadata.

## Milestone 2: Real Cubism Export Probe

Connect a licensed Cubism automation command and validate a real runtime bundle.

## Milestone 3: Real Segmentation Providers

Add SAM2/MediaPipe-style segmentation and VLM critique providers behind the same service contract.

## Milestone 4: Layer Decomposition and Inpainting

Generate Cubism-ready layered intermediates with confidence and correction metadata.

## Milestone 5: Rigging Research

Expand from curated anime samples to broader poses, complex clothing/hair, backgrounds, and eventually arbitrary images.
